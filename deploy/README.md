# Deploying the Admin Site

Runs on the same VPS as the Backend, as its own docker compose project in `/opt/blacmusic/admin`
(the `pk` user cannot create folders in `/opt` itself). It joins the Backend's private network
(`blacmusic_default`) and calls the API at `http://api:8080`, so admin traffic never leaves the machine and the
API sees the visitor's real address for its sign-in lockout.

```
Cloudflare ──> nginx :443 (blacadmin.pkasemer.com) ──> admin site 127.0.0.1:3100 ──> api (docker network)
```

## Every deploy

```bash
deploy/ship.sh pk@178.79.160.251 [path/to/ssh_key]
```
Builds the image on your machine, copies it over, creates `/opt/blacmusic/admin/.env` with a fresh `SESSION_SECRET` the
first time, and restarts the container. Re-running keeps the same `.env` (and so keeps people signed in).

## One-time setup

1. **Backend**: `EDITORIAL_OWNER_EMAIL=admin@blactechmedia.com` in `/opt/blacmusic/.env` (done), the account must exist
   with role `admin` and a confirmed email (done). Recreate the API after changing it:
   `cd /opt/blacmusic && docker compose -f docker-compose.prod.yml --env-file .env up -d api`
2. **nginx** (as root): `scp deploy/nginx/blacadmin.conf root@HOST:/tmp/ && ssh root@HOST 'bash -s' < deploy/nginx-setup.sh`
3. **DNS** (Cloudflare): an `A` record `blacadmin` -> the server's address (proxied is fine). Use a one-level name
   (`x.pkasemer.com`), as for the Backend. SSL/TLS mode **Full (strict)**.
4. **Certificate**: add the name to the Backend's certificate (needs the DNS record first):
   ```bash
   ssh root@HOST 'certbot certonly --webroot -w /var/www/certbot --cert-name blacmusic --expand \
     -d blacmusic.pkasemer.com -d blacmedia.pkasemer.com -d blacadmin.pkasemer.com \
     --deploy-hook "systemctl reload nginx" && nginx -t && systemctl reload nginx'
   ```
   The nginx files point at `/etc/nginx/blacmusic/*.pem`, which link to that certificate.

## Settings in `/opt/blacmusic/admin/.env` (see `env.example`)

| Variable | Meaning |
|---|---|
| `SESSION_SECRET` | encrypts the session cookie; generated by `ship.sh`; changing it signs everyone out |
| `SITE_ORIGIN` | the public https address; the site refuses to start without an https origin |
| `IMAGE_ORIGINS` | where artist and cover images are served from (page CSP) |
| `SESSION_IDLE_MINUTES`, `SESSION_ABSOLUTE_MINUTES` | idle (sliding) and maximum session length |

Fixed in the compose file: `BACKEND_URL=http://api:8080` (do not use the public https name: nginx would overwrite the
visitor's address), `TRUST_PROXY=true` (port 3100 is bound to 127.0.0.1, only nginx reaches it), a read-only container
running as a non-root user with no capabilities and a 256 MB limit.

## Operating it

```bash
cd /opt/blacmusic/admin
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs -f admin
```
Optional extra protection: put the site behind Cloudflare Access, or restrict `blacadmin` in nginx to your own addresses.
